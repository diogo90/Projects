Moneyball Target shortlist

Ranked by performance score. Each target's pre-tournament value is at or below the median value for their position (shown as % of median). Value change = 12 months after the tournament final.

Sources: StatsBomb Open Data (event & lineup data, Euro 2024 + Copa América 2024) · Transfermarkt via Kaggle (davidcariboo/player-scores). Performance score = position-weighted percentiles of per-90 metrics (npxG, xA, progressive passes/carries, box entries, dribbles, pressures, defensive actions). Players are matched across sources by nationality-blocked fuzzy name matching. Small samples (tournament minutes) and a back-test on a single tournament window: treat the results as a hypothesis generator, not a verdict.
