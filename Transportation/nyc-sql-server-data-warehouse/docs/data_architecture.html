NYC TLC Data Warehouse: High-Level Architecture

Medallion architecture on SQL Server Express. Six sources are pulled and parsed into a landing zone, bulk-loaded into Bronze, cleansed and conformed in Silver, and modelled as a star schema in Gold. All three layers are orchestrated and audited from the etl schema.

Why this is safe to re-run

Atomic loadsTruncate + insert share one transaction; a failure rolls back to the previous data
Stable keysDimensions are upserted, so surrogate keys never change between runs
Fail loudlyErrors are logged, then re-raised with THROW
